# AHK 工具箱

窗口字体放大、应用快捷键和 Codex 自动重试共用一个托盘入口。双击托盘打开设置，日常只运行 `main.ahk`。

## 目录与运行

本工具的代码、配置、测试输出和备份统一留在 `D:\Bin\AHK`，不安装到系统盘，也不创建开始菜单项。

```text
AHK/
├─ main.ahk、launcher.ahk  启动入口
├─ src/                    自有代码
├─ Lib/UIA.ahk              唯一的第三方 UIA 库
├─ data/toolbox.ini         日常配置（当前用户可写）
├─ tests/                   测试；结果放在 tests/output
└─ backup/                  历史备份
```

目录和文件的权限已恢复为加固前的状态，代码、配置均可普通编辑；父目录不再额外限制改名，没有权限管理或部署步骤。只有一份 D 盘代码。已有的64位 AutoHotkey解释器继续使用，本工具不另行安装解释器。

保留低维护成本的运行安全措施：自动重试不提权，系统程序使用固定路径，配置输入校验和原子保存，重试前复核按钮状态。主进程的管理员权限用于处理管理员窗口。可编辑代码不具备额外的防篡改保证，应只运行和更新自己信任的脚本。

## 日常设置

- 托盘有三个模块开关、重新加载、打开脚本目录、打开配置目录及原生 AHK 菜单。
- 设置窗口使用12pt字体：窗口字体 → 排除规则 → 快捷键 → Codex 重试。
- 列表支持新增、双击编辑和删除；点主窗口“保存”才应用，取消不会保存草稿。
- 快捷键和排除条目共用编辑弹窗流程，取消后恢复父窗口；草稿与已生效配置保持独立。
- 外部编辑 `data/toolbox.ini` 后先 Reload；旧界面检测到文件变化时会拒绝覆盖它。
- 原生 Pause/Suspend 只影响主进程，日常请用模块开关控制独立的自动重试。

主进程为处理管理员窗口请求管理员权限。取消提权后，只能处理普通权限允许的窗口。配置是数据，控件条件不会被当作脚本执行。

## 快捷键

默认 Win+W 切换 Terminal、Win+S 切换 Everything、Win+C 切换任务管理器。目标已在前台时，Terminal/任务管理器最小化，Everything 关闭窗口。

自定义应用支持启动、唤醒、再次按键最小化，按所选 exe 文件名识别窗口；复杂命令行、启动后转交其他进程的启动器不属于简易编辑器范围。`#` 为 Win，`^` 为 Ctrl，`!` 为 Alt，`+` 为 Shift。Win+F11 留给字体工具，重复绑定会被拒绝。

普通应用通过桌面 Explorer 启动，避免继承管理员权限。任务管理器固定使用 Windows 系统目录下的 Taskmgr.exe。Everything 路径只保留在 INI 的 `EverythingPath`，不占用日常界面。

## 窗口字体与排除规则

原生 DPI 优先，兼容的经典 Win32 控件使用字体/布局兜底。默认原生目标175%，兜底微软雅黑12pt；已达到175%的原生窗口直接返回。若兜底字号超出工作区，以0.5pt步长、最多降低2pt，仍放不下则跳过。

主要处理标准 `#32770` 对话框及已有 MMC 支持范围；不保证任意自绘程序都能自动重排。原生路径使用未公开的 `NtUserForceWindowToDpiForTest`，Windows 更新后的兼容性仍需验证。Win+F11 可处理当前支持的窗口并显示结果。

当前仅有两条初始排除：“文件属性窗口”和“DirectUI 控件”。文件属性作用于两条路径，DirectUI 仅限制字体兜底。TrafficMonitor 和文件选择框的专用排除已删除，没有逐条开关或隐藏的额外默认排除；删除保存后不会自动补回。

文件属性内部四种特征在真实测试中都有独立命中的情况，故保留识别范围，只合并重复的窗口/页签判断。GUI 仅编辑名称和窗口匹配；高级控件条件和 Scope 保留在 INI 中，界面编辑不会丢掉它们。

高级条件：每行都须满足，`A | B` 表示任选，`A > B` 表示直接父子，`Button@1` 表示类名和 ID，`ComboBox*` 表示前缀，`:root` 为目标窗口，`{1,2/3}` 要求直接子控件有 ID 1 且有 2 或 3。Scope 为 `all` 或 `legacy`。

修改字体、DPI 或排除后重开目标窗口测试；退出不会强行撤销已应用的界面。暂停字体模块保留现有窗口状态，恢复时不重复放大。

## Codex 自动重试

默认关闭，开启后每60秒检查一次，可设15～3600秒。独立工作进程始终使用桌面用户的普通权限，拒绝管理员身份；关闭后退出，不增加常驻启动助手。

保存字体、快捷键等无关设置不会重新计算重试等待时间；只有检查间隔改变时才重新计时。

仅调用输入框中唯一、启用且名称精确为“继续”的按钮，使用 UIA Invoke，不发送鼠标键盘、不还原窗口、不切换聊天。调用前复核状态，同一按钮不连续重复触发。“停止”“发送”会跳过。

可见或最小化主窗口优先，托盘隐藏后跟踪同一窗口。隐藏后是否可用取决于应用是否保留按钮接口；不可读或状态不确定时安静跳过。UIA 提供方是否自行激活窗口仍由应用实现决定。

UIA 只由工作进程加载，不占用主进程。连接和操作超时设为500ms，但整个查询可能包含多次操作。参数只初始化一次，按窗口事件和定时检查的实际需要工作，没有全桌面连续轮询。

## 验证与维护

代码按职责拆分：`toolbox` 管理界面和模块，`toolbox_settings` 处理配置，`hotkeys` 处理绑定，`process_launch` 负责普通权限启动；字体部分分为路径选择、原生 DPI、窗口事件、字体资源和排除条件。

常用隔离测试：

- `tests/toolbox_test.ahk`：配置保存/回滚、列表编辑、重试防误触、快速启停。
- `tests/exclusion_rules_test.ahk`：控件匹配、组合条件及排除作用范围。
- `tests/window_events_test.ahk`：事件处理、暂停恢复、50次资源循环。
- `tests/process_security_test.ahk`：普通权限子进程及自动重试启停检查。
- `tests/codex_retry_probe.ahk`：只读查看 Codex 按钮接口，不点击。
- `tests/run_file_picker_test.ps1`：在独立测试桌面打开并取消8种文件选择方式。
- 加 `-TestScript file_properties_test.ahk -TimeoutSeconds 90` 可对照40个属性页状态。

实际对照发现：多数文件选择框在删除专用排除后仍被 DirectUI 阻止兜底；原生 PMv2 窗口本身已为175%，布局不变。文件夹选择框则可能进入字体兜底，本机测试的标准按钮没有越界。这不能外推为所有程序都一样。

资源循环中内存基本稳定、句柄和GDI没有累计增长。性能数字取决于窗口复杂度和目标进程响应，不能保证任何窗口都在固定时间内完成。测试按需运行，不参与日常后台轮询。
